## 🚀 Projetos em destaque

### 🤖 Squad 13 — Agente de IA para suporte de TI

Projeto acadêmico em equipe para desenvolver um agente que consulta uma **base de conhecimento e chamados de TI** em um ambiente de laboratório com **GLPI 11**.

- Integração com a API do GLPI e tratamento de dados de chamados e artigos;
- Busca semântica com **SentenceTransformers/MiniLM**, embeddings e similaridade;
- Organização do backend em **Python** e validação com testes automatizados;
- Evolução da solução com **FastAPI** e interface em **React**, conforme o planejamento do projeto.

**Contexto:** projeto acadêmico em desenvolvimento colaborativo, com funcionalidades em diferentes estágios de implementação.

### 🗺️ CondoRoute — Rotas e QR Codes para condomínios

Projeto em equipe voltado à localização de residências dentro de condomínios, com geração de **QR Codes** para facilitar o acesso a rotas.

- Desenvolvimento de funcionalidades em Python;
- Integração com banco de dados **MySQL**;
- Utilização de **Docker** no ambiente do projeto;
- Construção e organização da aplicação em equipe.

### 🛒 Sistema de Vendas em Python
